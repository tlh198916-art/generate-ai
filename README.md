# Generate AI Landing Page

A polished Stage 1 landing page for **Generate**, an AI website and app builder.

## Stack
- Next.js 14
- React 18
- TypeScript
- Plain CSS, no UI dependency

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Deploy to Vercel

1. Push this folder to a GitHub repository.
2. Open Vercel and import the GitHub repository.
3. Framework preset: Next.js.
4. Build command: `next build` (Vercel can detect this automatically).
5. Click Deploy.

## Stage 1 scope

The page includes:
- Responsive landing page
- Generate branding
- Hero and CTA
- Social sign-in UI for Google, Facebook, Apple, email, phone, and SSO
- Social proof section
- App/website showcase gallery
- How-it-works section
- AI idea prompt UI
- Final conversion CTA
- Mobile navigation

The sign-in and AI generation controls are intentionally demo actions. They should be connected to real authentication, billing, AI generation, and app publishing in Stage 2.
